#🩸 Blood C+
Курсовой проект по ПМ / Бизнес-анализу

Информационная веб-платформа для автоматизации взаимодействия между донорами крови и медицинскими центрами.

#📄 Бизнес-анализ: 
https://www.canva.com/design/DAHAYHlam6c/ZvH2MZs-de9VBOilDMmIEQ/edit
📌 Цель проекта
Разработать MVP веб-системы для:
регистрации доноров и медцентров
создания и обработки заявок на донорство
хранения данных и анализов
управления процессом сдачи крови

#🧠 Выполненный бизнес-анализ
В рамках проекта выполнены:
✅ SWOT-анализ
✅ SMART-постановка целей
✅ User Stories (донор / медцентр / гость)
✅ Функциональные требования
✅ Приоритизация (MoSCoW)
✅ BPMN-диаграммы процессов
✅ Проектирование базы данных (таблицы: Донор, Медцентр, Запрос, История)
✅ Диаграмма Ганта (6 месяцев реализации MVP)

📊 Ключевая ценность
Ускорение поиска доноров
Повышение прозрачности процесса
Централизованная база данных
Снижение нагрузки на клиники
